01 / Overview

AI powered clinical support in a centralized SaaS platform

AnamNex is a medical SaaS platform developed to support emergency physicians in their daily clinical workflows through artificial intelligence.

The platform focuses on speed, diagnostic support and centralization of clinical information inside a secure and intuitive web application.

Physicians can upload ECG files and images for automated analysis, while medical images such as wounds and skin lesions can be processed through computer vision services.

The application was designed around asynchronous AI processing so that complex medical analysis could run in the background without blocking the physician's interface.

I built the platform using Laravel and Nginx, with Vanilla JavaScript powering the dynamic frontend and Redis supporting queue processing and caching.

04 / Architecture

Designing around asynchronous medical AI processing

One of the main architectural challenges was processing complex medical AI operations without blocking the physician's workflow.

ECG analysis and medical image classification can require significant processing time. Executing those operations directly inside a normal web request would create unnecessary delays and reduce the responsiveness of the application.

I implemented Laravel's queue system with Redis and Horizon so that analysis tasks could run asynchronously in the background.

The frontend can therefore submit an examination and continue operating while the backend processes the AI analysis.

Once the analysis is complete, the application can notify the physician and make the generated report available through the platform.

AnamNex is a complete medical SaaS platform developed to support emergency physicians in daily clinical practice using artificial intelligence at the point of care.

The platform focuses on speed, diagnostic support and centralization of clinical information in a single secure environment.

The system performs automated ECG analysis, processing technical files such as .mat and .hea as well as ECG images.

Medical images can also be uploaded for automated analysis using computer vision models designed to support wound, lesion and dermatological image classification workflows.

The client required a scalable, high performance web application capable of handling asynchronous AI inference while maintaining medical data privacy and delivering fast results.

I built the platform using Laravel on Nginx, with Vanilla JavaScript powering dynamic frontend interactions. The backend manages physician authentication, patient episode linking, queue jobs for AI analysis and secure integrations with specialized medical AI services.

One of the technical challenges was processing technical ECG files containing raw signal data. I implemented dedicated backend services to process these files and prepare the required data for the AI inference workflow.

Another challenge was maintaining fast turnaround times while processing AI analysis under potentially heavy clinical workloads. Laravel queues, Redis and Horizon allow analysis tasks to run asynchronously without blocking the user interface.

For data management, I implemented automated scheduled commands to anonymize applicable patient data after the defined retention period.

The architecture was also designed to allow additional medical image types and AI services to be integrated through modular backend services.

11 / Key Takeaway
Complex medical AI workflows require strong backend architecture.

AnamNex required more than connecting an AI service to a web application.

The platform needed to manage physicians, patients, medical examinations, file uploads, AI analysis jobs, generated reports, notifications and automated data management.

Laravel provided the application architecture, while Redis and Horizon handled the asynchronous processing required for complex AI operations.

The result is a centralized clinical platform where technically complex AI workflows can be integrated into a practical physician facing application.
