01 / Overview

Turning ordinary pet photos into AI generated artwork

Phopet is an AI powered platform designed specifically for pet owners who want to transform ordinary photographs of their pets into high quality digital artwork.

Users can upload approximately 10 to 20 photos of their pet and use those images to train a custom AI model.

Once training is completed, users can generate images through a collection of themed albums covering concepts such as Superheroes, Travel, Studio and Dystopian artwork.

The platform also supports image upscaling for higher resolution artwork suitable for printing.

The application required a backend architecture capable of handling long running AI operations, user accounts, credit based payments, image generation and background processing.

I built the platform using Laravel and Nginx, with JavaScript powering the dynamic frontend interactions and Redis handling asynchronous processing and caching.

04 / Architecture

Designing around long running AI operations

One of the central architectural challenges was the AI model training process.

Training a pet model can take approximately 30 to 60 minutes. Running that process directly inside a normal web request would create a poor user experience and potentially block server resources.

I therefore implemented Laravel's queue system with Redis so that training jobs could be processed asynchronously.

The user can submit their pet photos and leave the training process running in the background instead of remaining on a loading screen for the entire duration.

Once the model is ready, the platform can notify the user through Laravel Notifications.

07 / Payments

Credit based payment architecture

Phopet uses a credit based purchasing model rather than requiring users to maintain a recurring subscription.

I implemented the backend logic required to manage user credits and connect purchases with the user's account.

This allowed the platform to connect payment transactions with image generation usage while keeping the user account and credit balance centralized within the Laravel application.

The welcome package starts at €9.90 for 50 generated images.

09 / Automation

Automated maintenance and data cleanup

The platform also required automated maintenance so that inactive accounts and generated data would not accumulate indefinitely.

I implemented scheduled Laravel commands that identify inactive user data and permanently remove applicable models and images after the defined retention period.

This keeps the database and stored media more manageable while supporting the platform's privacy and data management requirements.

14 / Key Takeaway
Complex AI workflows can still feel simple to users.

Phopet required more than connecting an AI API to a website.

The platform needed a complete backend system capable of handling users, payments, credits, uploaded images, AI model training, background jobs, notifications and automated maintenance.

Laravel provided the application architecture, while Redis and queues solved the challenge of long running AI operations.

The result is a structured AI platform where the complexity of model training and backend processing remains largely behind the scenes, allowing users to focus on creating artwork from their pets.
